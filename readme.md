# Radial Metronome
The novel interaction is to set subdivision to 0. Phase-free metronome. The point is to allow borrowing time without repaying it.

For example, initially you appoint the top (\theta=0) as the barline. You play a fermata. As you go on, you can freely appoint a different phase as the barline. Steady BPM before and after the fermata.
